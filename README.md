# Nadim Assignment-6 FITLOG  Workout Library

FITLOG is a responsive workout library web application built with Next.js and TypeScript. Users can explore different workouts, view detailed exercise information, add workouts to their daily plan, and save workouts for later.



## Technologies Used

 Next.js
 React
 TypeScript* Tailwind CSS
 DaisyUI
 React Icons
 React Toastify
 REST API

## Features

 Browse a complete workout library with workout details.
 View individual workout details including description, muscle groups, equipment, sets, reps, duration, calories, and instructions.
 Add workouts to today's plan and manage the selected workouts.
 Save workouts for later and manage the saved list.
 Track total exercises, workout time, and calories in My Plan.
 Sort workouts by duration, calories, and rating.
 Mark planned workouts as completed.
 Remove workouts from Today's Plan or Saved list.
 Responsive design for mobile, tablet, and desktop devices.
 Toast notifications for important user actions.
